# 📚 Perfil Académico — Base de Datos MySQL

## 👨‍🏫 Descripción

Este proyecto contiene una base de datos relacional desarrollada en **MySQL** para organizar y representar mi perfil académico y profesional.

La base de datos permite estructurar información relacionada con formación académica, experiencia, producción científica, artículos, proyectos y otros elementos relevantes de un perfil profesional.

## 🗄️ Tecnologías utilizadas

* MySQL
* SQL
* MySQL Workbench
* Git
* GitHub

## 📊 Base de datos

El proyecto incluye el archivo:

```text
database/
└── perfil_academico.sql
```

Este archivo contiene la estructura y los datos de la base de datos `perfil_academico`.

## 🎯 Objetivo

El objetivo del proyecto es demostrar el diseño y manejo de una base de datos relacional utilizando MySQL, aplicando conceptos como:

* Diseño de tablas
* Claves primarias
* Claves foráneas
* Relaciones entre entidades
* Integridad de datos
* Consultas SQL
* Organización de información académica y profesional

## 🔎 Ejemplo

Una de las entidades del proyecto es `articulos`, utilizada para almacenar información relacionada con publicaciones académicas.

Entre sus campos se encuentran:

* `id`
* `perfil_id`
* `titulo`
* `revista`
* `anio`
* `doi`
